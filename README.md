# casual-tag-market-research

休闲游戏多品类「题材 × 呈现」供给研究技能。用 Sensor Tower 的收入与下载圈定头部与新品，为每款产品打可追溯的标签，交叉成供给差矩阵，最终输出一份可离线打开的单文件看板。

当前版本 **v0.1.3**，变更记录见 [CHANGELOG.md](CHANGELOG.md)。

## 功能

- **品类范围**：合成（二合与三合合并统计）、三消、混变益智、模拟经营，共四类。试点档可只跑合成一类。
- **标签体系**：主题材（一级 › 二级）、呈现、融合三个主槽，每款产品取 2–3 个；叙事类型与叙事强度各占一维，不计入主槽。
- **可追溯**：每个标签绑定一条非买量证据（商店描述、实机截图、玩家评论或公开评测），证据来源与原文一并留档。
- **质量门槛**：词表经收敛后由人签字；独立上下文盲测要求主题材与呈现一致率均不低于 80%，标签集合重叠率不低于 75%。
- **数据纪律**：所有数字只取 Sensor Tower 双端合并口径；第三方商店元数据仅用于描述与截图，不进入计算。

## 产出

| 产出 | 内容 |
|---|---|
| 市场盘面 | 四品类近六个月收入、下载、环比与头部集中度 |
| 产品档案 | Top10 与近十二个月新品的产品卡，含题材、呈现、融合标签与证据出处 |
| 供给差矩阵 | 主题材与呈现两个切面的密度与收入分布，附高频组合表 |
| 机会卡 | 全量档输出 3–5 张立项方向卡，含适配条件、反例与代价；试点档仅列判据占位 |
| 影视借鉴 | 按高频现状标签挑选的剧集与电影，附年份与完整剧情段落 |
| 看板 | 单文件 HTML，可离线打开与打印，另附分体版与图片目录 |

## 安装

```bash
git clone https://github.com/Hayasui/casual-market-research.git
```

克隆到本地技能目录即可，技能自带可执行脚本。

### 环境要求

- Python 3.11 或更高版本，仅用标准库。
- 可访问 Sensor Tower 的项目工作区；个人空间无法调用该数据源。
- 可选：第三方商店元数据通道，用于补齐英文描述与商店截图。
- 磁盘占用约 10 MB，另加看板图片。

## 使用

在助手会话中提出需求，技能会先确认统计窗口与品类范围：

> 帮我做一份休闲品类题材供给差看板，先跑合成一类。

流水线分五段：取数、打标、矩阵与机会卡、看板、归档。打标段中，受控词表收敛后会停一次，等待人工批复，之后才进入闭集定标与盲态重测。

## 目录结构

```text
casual-tag-market-research/
├── SKILL.md                 技能说明与流程总览
├── configs/                 品类定义、词表约束、交付策略
├── references/              五个阶段的规则与提示词模板
├── scripts/                 取数、打标质检、图表、看板编译
└── assets/                  看板样式与静态模板
```

## 适用范围

适用于休闲品类的选题与供给判断：某个题材有多少人在做、做成什么样、哪一块还空着。

不适用于以下任务，请改用对应技能：

- 单品类玩法机制竞品深挖、付费循环拆解、YouTube 社区反馈报告：`game-market-competitor-report`。
- 围绕指定影视或 IP 池做 1–5 星改编适配评级：`topic-adaptation-research`。
- 文化或时代背景专题研究：`cultural-era-background-report`。
