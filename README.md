# casual-tag-market-research

把休闲游戏市场的题材供给摊成一张可追溯的看板，用 Sensor Tower 的收入与下载说话。

## Why Install This Skill

如果你正在为休闲品类选题，最耗时的往往不是找产品，而是把「这个题材有没有人做、都做成什么样、哪一块还空着」讲清楚。散在十几个榜单与商店页里的判断，最后常常只剩一句「感觉挺挤」。

这个技能把这条链路收成一条流水线：先按收入与下载圈出每个子品类的头部与新品，再给每款产品贴上能回到截图的题材与画风标签，最后把标签与品类交叉成一张供给差矩阵。空位与扎堆因此变得可见，而不是靠印象。

它不替你做立项判断，只把证据摆齐。每一条结论都能点回到具体产品、具体截图与具体读数。

## What You Get

| 产出 | 内容 |
|---|---|
| 市场盘面 | 五个子品类近六个月收入、下载、环比与头部集中度 |
| 产品档案 | 头部与新品的产品卡，含题材、画风与证据出处 |
| 供给差矩阵 | 题材乘品类的密度与收入分布，空位与扎堆一眼可见 |
| 影视借鉴 | 按题材方向挑选的剧集与电影，附完整剧情梗概 |
| 看板 | 单文件 HTML，可离线打开、可打印 |

## Quick Start

这个技能自带可执行脚本，不是纯参考型，因此给出最小步骤。

- [Required] 执行 `git clone https://github.com/Hayasui/casual-market-research.git`，克隆到本地技能目录。
- [Optional] 执行 `git log --oneline -3` 确认版本，当前为 v0.1.2。
- [Afterward] 在助手会话里说一句「帮我做一份休闲品类题材供给差看板」，技能会先与你确认统计窗口与品类范围。

## Triggers

- 休闲品类题材看板
- 二合、三合、三消、模拟经营、混变的题材供给差
- 头部产品的题材与画风标签
- 立项题材的空位与扎堆

## Requirements

- Python 3.11 或更高版本。
- 可访问 Sensor Tower 的项目工作区；个人空间调不到该数据源。
- 可选：第三方商店元数据通道，用于补英文描述与截图。
- 磁盘约 10 MB，另加看板图片。
