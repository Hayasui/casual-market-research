# Stage 4：看板编译、脱敏验收与交付规范

本阶段目标：由 `compile_report.py` 与 `research_tools.py` 将前三阶段的结构化 JSON 编译为**「一屏概览 + 矩阵与品类明细 + `<details>` 折叠深读」的离线双版看板 HTML**，过完脱敏扫描与无头浏览器中文视觉目检，归档至知识库并附固定下载说明。

**严禁手工编写长篇 HTML**；任何正文或数据改动均须先改上游 JSON，再重新执行本页四步构建链。

## 二、零 JS 与全量版内联脚本白名单

脚本模式由 `configs/subgenres.json` 的 `presets.<mode>.html_script_mode` 与 `configs/workspace.json` 的 `delivery_policy.script_modes` 联合控制：

1. **`pilot` 模式（`--script-mode zero_js`，硬锁零脚本）**：
   - `html_delivery.py` 硬性禁止页面出现任何 `<script>` 标签；
   - 全部浏览交互由纯 HTML + CSS 实现（左侧 `position: sticky` 导航、`<input type="radio">` 品类 Tab、`<details>` 展开折叠、`:target` 词表高亮、横向滚动表格）。
2. **`full` 四品类全量版（`--script-mode whitelisted_inline_js`）**：
   - `html_delivery.py` 仅放行**至多 1 个**带有属性 `data-approved-inline="dashboard-ui"` 的内联 `<script>` 块，且同时通过五项静态门禁：
     1. 有效代码行数 **≤ 150 行**；
     2. 无 `src` 属性、零外部脚本/CDN 依赖；
     3. 零 `eval`、`new Function`、`fetch`、`XMLHttpRequest`、`WebSocket`、`document.write`；
     4. 仅提供四项纯本地 DOM 交互：点击 Tag 胶囊跨品类高亮/筛选命中产品、点击数值表头升/降序重排、一键全展/全折 `<details>`、跨区锚点切 Tab 与自动展开来源折叠层；
     5. **禁脚本降级可读**：在浏览器禁用 JS 时，纯 CSS Radio Tab、锚点跳转与原生 `<details>` 仍保证 100% 内容完整可读。

## 三、标准编译、校验与脱敏命令顺序

在 `<报告目录>` 全部上游 JSON 与 SVG 图表就绪后，按以下固定顺序执行 **5 条命令**（全部退出码须为 `0`；`checkpoint --stage stage4_built` 会强检根目录的 `*.base64.html` 与 `*_bundle.zip`，后者由 `pack-bundle` 生成，因此第 5 条收口命令必须排在 `pack-bundle` 之后，落盘 `stage4_built` 三件套，非停点阶段不生成 `handoff_questions.md`）：

```text
# 1. 编译模板与交付清单（检查缺项闸门、full 机会卡 6 栏或 pilot 占位屏、启用时核验影视 2–3 段、年份及禁填项，预处理来源脱敏）
python -B <Skill目录>/scripts/compile_report.py build \
  --out-dir <报告目录> \
  --preset <pilot|full>

# 2. 生成双版 HTML（<报告名>.html + <报告名>.base64.html + image/）
python -B <Skill目录>/scripts/research_tools.py html \
  --input <报告目录>/research/delivery-input.json \
  --output <报告目录> \
  --metadata <报告目录>/research/delivery.json \
  --script-mode <zero_js|whitelisted_inline_js>

# 3. 校验双版 HTML 内容一致性、[[metric]]/[[cite]]/内部锚点与脚本白名单
python -B <Skill目录>/scripts/research_tools.py validate \
  --input <报告目录>/research/delivery-input.json \
  --output <报告目录> \
  --script-mode <zero_js|whitelisted_inline_js>

# 4. 终稿全文脱敏扫描 + 单文件体积校验（< 3 MB）+ 打分体源码包 _bundle.zip
python -B <Skill目录>/scripts/compile_report.py pack-bundle \
  --out-dir <报告目录>

# 5. 阶段收口（须排在 pack-bundle 之后，校验产物并落盘 stage4_built 三件套）
python -B <Skill目录>/scripts/data_pipeline.py checkpoint --out-dir <报告目录> --stage stage4_built
```
